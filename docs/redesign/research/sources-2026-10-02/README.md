# Source candidates for the 44 play drawings (2026-10-02)

First-pass research by two Codex (GPT-6-Sol) lanes, from web search only:
their shell had no network, so no image was opened. Treat every entry as a
lead, not a choice.

- `brief-common.md`: the brief both lanes followed (rights, whole figure, no
  nudity, size, link to the play, detail first).
- `codex-lane-A.*`: Aeschylus, Sophocles and Aristophanes (25 plays): 6 found,
  16 weak, 3 none (Knights, Wasps, Peace).
- `codex-lane-B.*`: Euripides (19 plays): 18 weak, 1 none (Medea, which
  already has a drawing).

"Weak" mostly means the lane could not see the full-size file to confirm the
figure is whole, clothed and at least 800 px tall. Each lane gave one
candidate per play, not the two or three the brief asked for. Before any of
these is drawn, someone has to open the file, check the figure, and confirm
the licence on the file page. Some leads are poor fits for line drawing
(mosaics for Hippolytus and Heracles) or show a play's ending (Ajax, Hecuba,
Iphigenia at Aulis).
