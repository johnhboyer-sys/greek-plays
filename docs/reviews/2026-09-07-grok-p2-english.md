# Adversarial review — P2-English (commit eacdd73), Grok static read, 2026-09-07

Findings for fix round P2c (English attachment) and P2d (speaker overrides), most severe first.

1. **Name-only English aliases cannot follow a referent that changes mid-play.** Helen: Coleridge tags the servant's entrance at 1512 `Second Messenger` (→ Second Servant) but the rest of that scene `Messenger`, which already means the sailor at 597; Phoenician Women / Antigone never print `Second Messenger`, so the second messenger's English is coloured as the first. Fix: line-scoped English overrides (`speakers.english_overrides: [{name, from, to, display}]`), mirroring the Greek `speakers.overrides` the sigla collisions in the comedies also need (P3.1).
2. **The 88 declared gaps are not an honest completeness claim.** The English exists in the TEI; on a speaker mismatch `_resolve_slice_anchor` redirects onto the nearest same-speaker speech (±3, then ±12) so the neighbour chunk swallows it and this speech renders the em-dash empty state. The shared note is also false for the Septem doublet seconds (`1:803.2`, `1:810.2`), Bacchae `843a/843b`, Medea `1270a`. **P2c rule:** attach English to the Greek segment that OWNS the printed `<l n>`, even on speaker mismatch; when one `<sp>` spans several Greek speeches emit one chunk per Greek segment (split at those line numbers); keep `english.gaps` only for speeches whose line numbers have no covering `<l n>` in the TEI; give repeated-ref seconds and suffix twins their own allow kinds.
3. `build/p2/declare-gaps.py` (a build-dir script, not shipped) ignored the stage1 return code and read the single-work scratch `alignment.json`, so a failed stage1 could splice another play's ids into a manifest; and its work list came from a green log, so it is not reproducible. Retired; any future gap tool takes the work list from `authors.yaml` and asserts the scratch spine's work id.
4. Lacuna auto-allow (`stage2_validate._play_line_lacuna_segment_ids`) checks `role == lacuna` on every line but not empty text, and the test never goes through `validate()`. Fix: require empty text too; test through `validate()` with Helen's double `post 1226` allowed and a mixed unmatched segment still failing.
5. Semichoruses collapse to one colour where the Greek prints only `Ημ.` (Septem exodos; Alcestis/Hippolytus/Orestes/Suppliants-eur First/Second half-chorus → Chorus). Fix with the same line-scoped Greek overrides as item 1 (First/Second Semichorus), then point the English half-chorus labels at those keys.
6. YAML quoting, `translations: []` replacement, footnotes flags: no corruption found; the writer must not be re-run against manifests that already carry `english:`.
